El maiz __Chapalote__ es un tipo de maiz perteneciente al _Grupo Chapalote_ con distintos usos culinarios, los cuales son los siguientes:
+ <u> Palomitas de maiz </u>: Al ser sus granos __duros y cristalinos__ son perfectos para hacer palomitas.
+ <u> Pinole </u>: Los granos se tuestan, muelen y se pueden combinar con agua y leche para hacer una __base energetica__.
+ <u> Esquites y elotes tostados </u>: Gracias a __su dulzor__, las mazorcas tiernas se pueden tostar y comerlas.
+ <u> Pozole seco y atoles </u>: Se usa para preparar __bebidas calientes espesas__.
+ <u> Masa para tortillas </u>: Aunque su __color cafe__ pinte las mesas, se puede usar para hacer tortillas con un gran sabor dulce.
